Checkout protocol

A fresh session, created on the server.

  1. The page loads public availability and the Turnstile site key with a same-origin GET request.
  2. After human confirmation and Turnstile verification, a same-origin POST asks the server to create one Stripe Checkout Session.
  3. The browser navigates only to the returned checkout.stripe.com URL. Stripe handles payment details.

No reusable Payment Link, Stripe secret, Turnstile secret, card field, or payment detail lives in this page or repository.
