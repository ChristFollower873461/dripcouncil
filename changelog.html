v1.13.0 - Run Lab Glow-Up

Released July 1, 2026. Static, read-only, local trace and local compare only.

  • Upgraded trace replay with readable metrics, event timeline, JSON tabs, and local privacy reminders.
  • Polished report builder v2 with live summary, schema links, export shapes, and compare handoff.
  • Added /compare.html for local-only comparison of report v2 JSON files.
  • Added /ui-map.json for selector, workflow, and schema discovery.
  • Added gauntlet verdict scoring, collab handoff lanes, and static commerce-boundary verdict cards.
