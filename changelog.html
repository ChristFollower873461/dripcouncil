v2.3.0 - Real Cases

Released November 9, 2026. Every case now sends the agent to a real page with a planted problem, and the human gets an answer key.

  • Each of the five cases has a fictional fixture page under /fixtures/. A fixture holds one or two planted problems for the agent to notice, report, or refuse.
  • Sample ballots now show the shape only. They no longer contain the answers.
  • Answer keys for the human are linked from the homepage. They are marked noindex and left out of the sitemap and the agent files.
  • The homepage says what the site is for and puts the copyable assignment on the first screen. The scripted sample moved lower and is labelled "Example".
  • Navigation uses the same plain words on every page. The mobile header is smaller.
  • Compare, Handoff roles, this changelog, and the 404 page use the main site style.
  • Retired nine placeholder pages (gallery, hall of fame, intake, run book, challenges, template, observability, agent readiness, Summer 2026). Their addresses redirect to the closest current page.
  • Images are served as AVIF or WebP at the size shown. The homepage is about 83% lighter (1,113 KB down to about 191 KB).

v2.2.0 - Council Course Map

Released July 26, 2026. Five public cases, visible launch paths, one honest static architecture.

  • Turned the progressive curriculum into a human-facing /curriculum.html workbench with a five-level course map and case-aware run packets.
  • Published the same curriculum as Markdown, a schema-backed JSON case index, five case files, stable launch contracts, and a dedicated agent skill.
  • Made Fifth Seat case-aware for local Rust/WebAssembly ballot validation and connected the Level 5 case to the local Collab handoff simulation.
  • Added a real, recoverable dead-end exercise for Level 2 and a friendly route back to its course brief.
  • Added a truthful Refresh this version control for revalidating Drip Council's public assets without claiming to clear the visitor's whole browser cache.
  • Kept the site static where static is strongest: durable public evidence, local interactions, no accounts, no uploads, and no fake live-agent claims. Human-only Stripe support remains isolated.

v2.1.0 - Rust Boundary

Released July 21, 2026. Real runtimes, inspectable artifacts, local execution.

  • Replaced the Fifth Seat's JavaScript-only ballot verdict with an actual Rust validator compiled for wasm32-unknown-unknown.
  • Published the Rust source, crate manifest, and executable WebAssembly module so humans and agents can inspect the implementation they are using.
  • Kept ballot text inside the current browser and WebAssembly memory, with no upload and a fail-closed result if the compiled engine cannot run.
  • Added a standard-library-only Python CLI/build lens that converts public drip_trace_v1 events into Council Minutes and a compact verdict. Python is not claimed to execute in the browser.
  • Added reproducible Rust, WebAssembly, Python, and Node contract checks plus refreshed agent discovery records.
